# Frontend do ss

Aplicação React/TypeScript compilada com Vite. A documentação completa, incluindo arquitetura, configuração e execução, está no [README principal](../README.md).

```bash
npm ci
npm run dev
```

Validação:

```bash
npm test
npm run lint
npm run build
```

O frontend isolado não fornece upload, WebSocket, mídia ou torrents. Use o Docker Compose na raiz para executar o sistema completo.
